# hisbase 对账清单

用于 Web 版与 VFP 旧系统并行验证：选同一批人员，在相同「当前执行工资」基准下对比试算/办理结果。

## 1. 抽样人员

建议每类至少 2 人：

| 类别 | 岗位前缀 | 等级（jx）示例 |
| --- | --- | --- |
| 机关公务员 | 01 / 02 / 03 | 含警衔、检察、审判、监察之一 |
| 事业人员 | 07–11 | 含教护龄 |
| 见习 | zwbm2 含 F | — |

记录：`dwbm`、`grbm`、当前 `hisbase.id`（sid 为空）、`jsnf+jsyf`。

## 2. 字段对账（办理前后）

对每条新写入的 `hisbase` 记录核对：

| 字段 | 说明 |
| --- | --- |
| `jslb` | 变动类别与 VFP 一致 |
| `jxjtbz` | 警衔（lb=jx）或监察（lb=mt）标准年月 |
| `jcjtbz` | 检察标准年月（lb=jc） |
| `spjtbz` | 审判标准（lb=sp） |
| `jxjt` | `jxjt+jcjt+spjt+mtjt` 合成（机关 01–03） |
| `hj2` / `bbz` | 合计 = 旧合计 + jxjt 差额（标准调标类） |
| `sid` | 旧记录指向新 id；新记录 sid 为空 |

| Web 菜单 | VFP | 验证步骤 |

## 4. 已知差异（记录于此）

| 项 | Web | VFP | 备注 |
| --- | --- | --- | --- |
| 监察标准字段 | `jxjtbz` + lb=mt | 无独立 `mtjtbz` 列 | 与旧库三字段模型一致 |
| 检察筛选 | `检察`/`检察官`，排除监察 | `AT("检")` | Web 避免监察误判 |

## 5. 差异处理

1. 截图或导出 Web 试算行与 VFP 表单数值。
2. 在「上机日志」查 `APPLY_*` / `ROLLBACK_*` 是否与操作一致。
3. 差异写入上表「已知差异」或提 issue，注明人员编码与年月。
